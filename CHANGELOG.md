# Changelog

## v1.0.0

First public-release package of Velide by Baloide.

- Electron desktop app with the same branded interface as the browser version.
- Windows x64 installer with desktop/Start menu shortcuts and a portable ZIP.
- In-memory text import from digital PDF, DOCX, TXT and Markdown.
- Side-by-side review, custom terms, four masking modes and TXT/clipboard export.
- Ten languages, supported system/browser locale detection and English fallback.
- Day, night and system themes.
- Baloide branding, copyright and visible application version in the footer.
- Parser budgets, regression checks, English documentation and SHA-256 release files.

Automatic masking requires human review. OCR, batch processing, in-place PDF redaction and signed Windows packages are not included.
